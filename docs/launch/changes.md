## GitHub release notes

> AAS v0.2.5 keeps isolated profiles in their own homes after account switches and removes existing links when you turn off sharing. Imported system profiles prompt you to activate the saved credential before launch.
>
> The proxy now reports interrupted responses as errors and discards buffered tool calls when upstream fails. BarShelf quota recovery alerts work alongside accounts such as Pi that report no remaining percentage. This release also updates the URL dependency and replaces Chrono with Jiff.
>
> Update with `brew upgrade aas` or reinstall from the [v0.2.5 release](https://github.com/Open330/aas/releases/tag/v0.2.5).
